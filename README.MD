# Learning Object Orientation in C#

This repository is a practical introduction to object-oriented programming (OOP) with C#.

## Topics

- Classes and objects
- Fields, properties, and methods
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction and interfaces

## Getting Started

1. Install the [.NET SDK](https://dotnet.microsoft.com/download).
2. Clone this repository.
3. Open the solution in your preferred IDE, such as Visual Studio or VS Code.
4. Run the examples and experiment with the code.

```bash
dotnet run
```
